# Reproducing and Extending COPOD

This repository supports a COMP8240 reproducibility project based on:

Li, Z., Zhao, Y., Botta, N., Ionescu, C., and Hu, X. (2020).  
**COPOD: Copula-Based Outlier Detection.**  
IEEE International Conference on Data Mining (ICDM).

## Project aims

1. Reproduce selected experiments from the original COPOD paper.
2. Compare the reproduced results with the published results.
3. Apply COPOD to new publicly available financial transaction datasets.
4. Construct controlled transaction anomalies and evaluate whether COPOD detects them.

## Repository structure

- `original_code/COPOD/`: official code released by the paper's authors
- `data/`: datasets used in this project
- `scripts/`: scripts written for reproducing and extending the experiments
- `results/`: numerical experiment results
- `figures/`: generated graphs and figures
- `environment/`: dependency and computing-environment information
- `report/`: project proposal and final report files
- `notes/`: research and experiment notes
